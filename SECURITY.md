# Security Policy

## Reporting a vulnerability

Please report security or privacy vulnerabilities privately through this repository's **GitHub Security Advisory** interface. Include the affected version, a minimal reproduction, impact, and any suggested mitigation.

Do not open a public issue, pull request, or discussion containing exploit details, credentials, private terminal content, local paths, or other sensitive evidence. Do not commit secrets or attach private application data. The maintainer will acknowledge a report, assess affected versions, and coordinate remediation and disclosure through the advisory.

## Supported versions

Only the latest release candidate and latest live-accepted release receive security fixes. Release lifecycle state is recorded in `docs/releases/catalog.json`.
